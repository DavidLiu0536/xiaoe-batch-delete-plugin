# 小鹅通考试批量管理工具

批量清理小鹅通后台「导入已有课程内容」产生的重复考试副本的 Tampermonkey 脚本。

## 功能

- **检测重复考试**：按名称分组，识别同一考试的多个副本（每组保留最早一条为原始）
- **删除勾选副本**：删除页面中勾选的副本
- **删除全部副本**：跨全部重复组删除副本（不受页面显示数量限制）
- **日期筛选**：只处理指定创建时间范围内的考试
- 删除过程带进度条，全程控制台日志

## 安装（老师端）

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 打开脚本地址：

   ```
   https://raw.githubusercontent.com/DavidLiu0536/xiaoe-batch-delete-plugin/main/xiaoe-batch-delete.user.js
   ```

   Tampermonkey 会自动弹出安装页，点击「安装」。

3. 访问小鹅通考试管理页：
   `https://admin.xiaoe-tech.com/t/exam/examination#/examIndex/examList`
   页面顶部会出现工具栏（白底、无图标的三个按钮）。

## 更新

脚本已配置 `@updateURL` 指向本仓库。Tampermonkey 会按设定周期自动检查更新，
也可在 Tampermonkey 面板中手动「检查更新」。版本号见脚本头部 `@version`。

## 使用建议

1. 点「检测重复考试」等分析完成
2. **先勾选 1 个副本试删**，确认控制台输出 `exam_id=ex_...` 且返回 `code=0`
3. 确认无误后用「删除全部副本」批量清理
4. 删除不可恢复，操作前请确认筛选范围（可用顶部日期筛选缩小范围）

## 注意事项

- 删除操作不可恢复，请谨慎使用
- 需要在已登录的小鹅通后台使用，脚本不保存任何凭据
- 每组重复考试会保留最早创建的一条作为原始
